# F06a — Omit unused term pages

Only the Atom term lookup's `include_pages=false` argument changes. Term resolution, required-error behavior and native slug semantics remain intact. The template consumes the slug, not its pages.

`tests/taxonomy_contract.py` differentially compares the baseline templates with this candidate, including Unicode taxonomy names, safe slugging, unused kinds, fallback banners and multilingual output. With `--full-prepared`, it copies the exact prepared corpus and checks both output equivalence and timing. Feed comparison ignores category order and formatting whitespace only; entry content, links and all other XML structure remain compared. The script's full timing wrapper uses Linux /usr/bin/time.

Measured alone on the audit corpus: 239.770s versus a fresh 363.278s baseline. Do not attribute the combined performance result to this argument alone. The separate F06b branch has different changes and is based on the same audited tip.
